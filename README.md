# 🔍 网盘搜 (pan-search)

本地网盘资源聚合搜索工具 —— **123云盘 / 夸克 / 阿里云盘 / 百度网盘 / 天翼 / 迅雷 / UC / 115 / PikPak / 磁力**，一站直达。

纯本地运行：无需注册、无需 API Key、零数据库，`npm start` 即用。

---

## ✨ 特性

- 🎯 **全平台覆盖** — 自动识别 10+ 网盘类型并打标，提取码自动识别展示
- ⚡ **三引擎聚合** — 资源聚合库（主）+ DuckDuckGo + Bing 并行搜索，单源失败不影响整体
- 🔁 **二段式搜索** — 针对异步数据源自动补捞晚到结果，冷门资源召回率大幅提升
- 🚀 **强制刷新** — 一键绕过缓存重新搜索一轮
- 🧹 **智能去重** — 同一分享的多版本自动合并（优先保留带提取码的版本），磁力链接按 btih 哈希去重
- 🛡 **质量过滤** — 自动剔除网盘官网普通页面，只保留真实分享链接
- 💾 **结果缓存** — 同一查询 10 分钟内秒回，降低被数据源频控的概率
- 🌐 **本地网页版** — 平台筛选、搜索历史、一键复制链接/提取码

## 🚀 快速开始

环境要求：Node.js ≥ 18（使用了内置 fetch / AbortSignal.timeout）

```bash
git clone https://github.com/HongKongDoll-cmd/pan-search.git
cd pan-search
npm install
npm start
```

浏览器打开 **http://localhost:3210** 即可使用。

自定义端口：

```bash
PORT=8080 npm start
```

## 📖 使用技巧

1. **关键词越短越好** —— 搜资源名本身（`三体` 优于 `三体电视剧网盘资源`）
2. **搜得少就点「强制刷新」** —— 主数据源的插件是异步模式，部分结果会晚到，刷新一轮通常能多出一批，等 10-20 秒
3. **用平台标签精确过滤** —— 只看 123云盘 / 只看夸克等
4. 引擎状态会显示在结果上方（如 `聚合库 42 条 · Bing 失败`），鼠标悬停可看失败原因

## 🏗 架构

```
server.js                 # Express 后端（约 400 行）
├─ 引擎1 聚合库 API       # 主引擎：TG频道 + 多插件聚合，自带提取码字段
├─ 引擎2 DuckDuckGo HTML  # 支持 site: 语法，精准定位网盘分享域名，3 次重试抗频控
├─ 引擎3 Bing             # 备用（部分网络环境下可用）
├─ 结果加工层             # 类型识别 / 提取码正则 / 去重 / 官网页过滤 / 相关度排序
└─ 缓存层                 # Map + 10min TTL + LRU 上限

public/                   # 前端单页（原生 HTML/CSS/JS，零框架零构建）
```

支持的平台识别：123云盘（含 123684/123865/123912/123952 等分享域族）、夸克、阿里云盘、百度网盘、天翼、迅雷、UC、115、移动云盘、微云、PikPak、蓝奏云、磁力链接。

## ⚙️ 数据源说明

- **主引擎**基于开源项目 [PanSou](https://github.com/fish2018/pansou) 的公共实例 API，聚合了数十个 Telegram 资源频道与搜索插件的结果，在此感谢原作者
- DuckDuckGo / Bing 用于补充深挖网盘官方分享域名下的页面，并从结果摘要中二次提取分享链接
- 主数据源偶发频控时自动重试（最多 3 次），仍失败则该引擎显示"失败"，其余引擎结果不受影响

## ❓ 常见问题

<details>
<summary>为什么有的引擎显示"失败"？</summary>

搜索引擎都有反爬与频控策略（DuckDuckGo 连续高频使用会暂时冷却）。单引擎失败不影响其他源的结果，稍后重试或点「强制刷新」即可。
</details>

<details>
<summary>搜不到资源怎么办？</summary>

① 换更短的关键词；② 点「强制刷新」等 10-20 秒；③ 把平台标签切回「全部」；④ 冷门资源确实可能全网无分享。
</details>

<details>
<summary>会泄露我的搜索记录吗？</summary>

不会。所有搜索请求由你本机直接发起，缓存只存在本机内存里，重启即清空，无任何上报。
</details>
